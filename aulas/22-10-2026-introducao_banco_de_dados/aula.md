## Anotações

Sistema Gerenciador de Banco de Dados (SGBD): os dados passam a ser naturalmente compartilhados entre as aplicações que se conectam ao banco.

### Cinco modelos

1. Modelo flat: dados tabelados em linhas e colunas.
2. Banco de dados hierárquico: como uma árvore de cabeça para baixo.
3. Banco de dados em rede: evolução da anterior — dá para andar de cima para baixo e lateralmente.
4. Banco de dados relacional: várias tabelas relacionadas entre si (estado da arte).
5. Banco de dados orientado a objeto: ainda não estão em plena utilização; são mais pesados que o relacional.

### Décadas

- Década de 1960: usava fita magnética para armazenar os dados.
- Década de 1980: cópias de segurança ainda em fitas magnéticas.
- Década de 1990: departamento de Tecnologia da Informação; surgiram os datacenters, onde são armazenados TB de dados.

### Processamento e SGBD

Processamento de dados: entrada → o computador processa → saída.

SGBD → middleware: é o meio do caminho entre a fonte de dados e as aplicações via web.
