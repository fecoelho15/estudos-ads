## O tema

Um computador é a união de duas coisas: o que você pode tocar e o que o faz trabalhar. Hardware é a parte física. Software é o programa. Um sem o outro não resolve o problema.

A propagação dos computadores veio dessa combinação. O hardware oferece funções genéricas: processar, guardar, mostrar, conectar. O software usa essas funções para criar programas úteis a muita gente. O hardware é a base. O software é o que se extrai dessa base.

## Hardware e software, em uma frase

- Hardware: instrumentos físicos, tangíveis. Você pode ver e tocar: placa-mãe, processador, memória, teclado, monitor, placa de rede.
- Software: programa. É a sequência de instruções que diz ao hardware o que fazer. Você não segura o software na mão; ele está nos arquivos e na memória.

A interação entre os dois é o que permite ao PC resolver problemas muito diferentes. A máquina não nasce sabendo editar texto, navegar na internet ou jogar. Ela nasce com capacidades. O software escolhe quais capacidades usar e em que ordem.

## O exemplo da placa de rede

Se você tentar se conectar à internet num computador sem placa de rede, não consegue. Falta o hardware que dá a capacidade de conexão.

O programa do navegador pode existir. Ele pede: "mande estes dados pela rede". Sem a placa, o pedido não tem para onde ir. Software sem o hardware correspondente não completa a tarefa. Hardware sem software fica parado: a placa existe, mas ninguém a usa.

## A analogia do automóvel

A montadora constrói o carro com peças que dão capacidades genéricas. Na imagem da aula:

| Peça do carro | Capacidade | No computador, a ideia |
| --- | --- | --- |
| Rodas | Geram movimento | Partes que fazem o sistema "andar": energia, disco, memória em uso |
| Freios | Para poder parar | Controle e interrupção: desligar, pausar, limitar |
| Volante | Mudança de direção | Controle do caminho: entrada do usuário, decisões |
| Motor | Para acelerar | Processador: a peça que executa e dá velocidade ao trabalho |

O carro pronto é o hardware: um conjunto de capacidades. O software é o que se faz com essas capacidades. O mesmo carro leva a família, faz uma entrega ou fica na garagem. A diferença não é a troca do motor a cada uso. É o modo de dirigir, a rota e o objetivo.

No computador, o mesmo processador e a mesma memória servem a um editor de texto, a um navegador e a um jogo. O que muda é o programa.

## Tipos de hardware

### Processamento

- Processador (CPU): executa as instruções. É o "motor" do computador.
- Placa de vídeo (GPU): especializada em gráficos e, em muitos casos, em cálculos paralelos.

### Memória e armazenamento

- Memória RAM: guarda o que está em uso agora. Rápida e volátil: ao desligar, o conteúdo some.
- HD ou SSD: guarda arquivos e programas de forma permanente. Mais lento que a RAM, mas não depende da energia.

### Entrada e saída

- Entrada: teclado, mouse, microfone, webcam, scanner.
- Saída: monitor, impressora, alto-falante.
- Entrada e saída: touchscreen, pendrive, placa de rede.

### Placa-mãe e energia

- Placa-mãe: conecta as peças. Sem ela, processador, memória e placas não se falam.
- Fonte: alimenta o conjunto com energia elétrica estável.

Cada peça é uma capacidade. Sem o monitor, não há imagem. Sem o teclado, a digitação não entra. Sem a placa de rede, a internet não sai.

## Tipos de software

### Software de sistema

Faz o hardware trabalhar de forma ordenada. O principal é o sistema operacional: Windows, Linux, macOS. Ele gerencia memória, arquivos, usuários e a comunicação com as peças. Sem sistema operacional, o usuário comum quase não usa o computador.

### Software aplicativo

Resolve um problema do usuário. Exemplos: navegador, editor de texto, planilha, aplicativo de mensagem, jogo. Cada aplicativo pede ao sistema operacional o uso do hardware.

### Firmware

Programa gravado dentro de um hardware específico, quase "colado" nele. Exemplos: BIOS ou UEFI da placa-mãe, software interno de um roteador. Fica entre o hardware puro e o sistema operacional.

## Como a interação funciona

1. Você abre um programa (software).
2. O sistema operacional coloca o programa na RAM e pede à CPU que execute as instruções.
3. Se o programa precisa mostrar algo, a GPU e o monitor entram.
4. Se precisa da internet, a placa de rede entra.
5. Se precisa gravar um arquivo, o SSD ou o HD entra.

O software decide o que fazer. O hardware executa. Se a capacidade física não existe, a etapa correspondente falha. É o caso da internet sem placa de rede.

Essa combinação abre soluções que ninguém planejou no dia em que o processador foi fabricado. O hardware nasceu genérico. Os programas posteriores inventam usos novos sobre a mesma base.

## Por que importa

Separar hardware e software evita um erro comum: culpar o programa por falta de peça, ou culpar a peça por falta de programa. Também explica por que atualizar o software muda o comportamento sem trocar a máquina, e por que trocar a máquina (mais memória, SSD, placa de vídeo) muda o que o mesmo software consegue entregar.

## Erro comum

Tratar "software" só como aplicativo instalado. O sistema operacional também é software. Tratar "hardware" só como a caixa. Teclado, monitor e placa de rede também são hardware.

Na analogia do carro: achar que o software é uma peça a mais soldada no motor. Software não é peça. É o uso, a sequência, o programa que aproveita as peças.
